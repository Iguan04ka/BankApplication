#  NeoStudy - Frontend Application

**NeoStudy** — это современное веб-приложение для управления образовательными выписками с красивым интерфейсом на React.

## ✨ Особенности

-  **Красивый дизайн** - Современный UI с Bootstrap 5
-  **Адаптивный интерфейс** - Работает на всех устройствах
-  **Безопасная аутентификация** - JWT токены и защищенные маршруты
- ️ **FSD архитектура** - Масштабируемая структура проекта
-  **Мягкие цвета** - Приятная сине-голубая палитра
- ⚡ **Быстрая разработка** - React 19, React Router v6, Axios

##  Быстрый старт

### Требования
- Node.js 16+ 
- npm 7+

### Установка

```bash
# Клонируйте репозиторий
cd "D:\JDK and IDEA\Projects JAVA\NeoStudyProject\front"

# Установите зависимости
npm install

# Запустите приложение

```

Приложение откроется на **http://localhost:3000**

##  Страницы

###  Домашняя страница (`/`)
Красивая целевая страница с:
- Героической секцией с приветствием
- 4 карточками с фичами
- CTA кнопками для входа/регистрации

###  Логин (`/auth/login`)
Форма логина в центре экрана (~1/3 ширины):
- Поля: Username, Password
- Кнопка "Login" с loader'ом
- Ссылка на регистрацию

### ✨ Регистрация (`/auth/register`)
Форма регистрации в центре экрана (~1/3 ширины):
- Поля: Username, Password
- Кнопка "Register" с loader'ом
- Ссылка на логин

###  Выписки (`/statement`)
Защищенная страница с формой выписки:
- Адаптивная сетка для полей
- Отправка данных на backend
- Отображение результата

## ️ Архитектура

Проект использует **Feature-Sliced Design (FSD)** архитектуру:

```
Layers (от верхнего к нижнему):
├── app          - Инициализация приложения
├── shared       - Переиспользуемые компоненты
├── features     - Бизнес-логика фич
├── pages        - Страницы приложения
└── auth         - Глобальное состояние
```

### Преимущества FSD
✅ Четкое разделение ответственности
✅ Легче масштабировать
✅ Проще найти код
✅ Меньше конфликтов при совместной разработке

##  Аутентификация

Приложение использует JWT токены для аутентификации:

- **Access Token** - для авторизованных запросов
- **Refresh Token** - для обновления токена

Токены хранятся в `localStorage`:
```javascript
localStorage.setItem('accessToken', token);
localStorage.setItem('refreshToken', refreshToken);
```

##  API

Backend доступен по адресу: `http://localhost:8085`

Настроено через `package.json`:
```json
"proxy": "http://localhost:8085"
```

### Endpoints
- `POST /auth/login` - Логин
- `POST /auth/register` - Регистрация
- `POST /auth/refresh` - Обновить токен
- `POST /statement` - Отправить выписку
